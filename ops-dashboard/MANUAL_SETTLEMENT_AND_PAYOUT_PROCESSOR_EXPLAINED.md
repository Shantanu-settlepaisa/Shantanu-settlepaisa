### System 2: Automated Payout System (Designed But Not Deployed)

**Architecture Overview:**
```
Settlement Approved 
    ↓
[settlement-scheduler.cjs]
    ↓ queueBankTransfer()
    ↓
INSERT INTO sp_v2_bank_transfer_queue (status = 'queued')
    ↓
⚠️ MISSING: payout-processor service (NOT DEPLOYED)
    ↓ (should call bank API)
    ↓
Bank API (ICICI/HDFC/Axis)
    ↓ returns real UTR
    ↓
INSERT INTO sp_v2_settlement_bank_transfers (with real UTR)
    ↓
Money credited to merchant
```

**The Missing Service: `payout-processor`**

**What It Should Do:**
1. Poll `sp_v2_bank_transfer_queue` for records with `status = 'queued'`
2. Call real bank APIs (ICICI Payout API, HDFC Payout API, etc.)
3. Send payment request to bank with merchant bank details
4. Wait for bank response with UTR number
5. Insert record into `sp_v2_settlement_bank_transfers` with real UTR
6. Update queue status to `'completed'`

**Pseudo-Code (What's Missing):**
```javascript
// File: services/payout-processor/payout-processor.cjs (DOES NOT EXIST)

class PayoutProcessor {
  async processQueue() {
    // 1. Get pending payouts from queue
    const pendingPayouts = await db.query(`
      SELECT * FROM sp_v2_bank_transfer_queue 
      WHERE status = 'queued' 
      ORDER BY created_at ASC 
      LIMIT 10
    `);

    for (const payout of pendingPayouts) {
      try {
        // 2. Update status to processing
        await db.query(`
          UPDATE sp_v2_bank_transfer_queue 
          SET status = 'processing', updated_at = NOW() 
          WHERE id = $1
        `, [payout.id]);

        // 3. Call bank API (this is what's missing)
        const bankResponse = await this.callBankAPI({
          amount: payout.amount_paise / 100,
          account_number: payout.account_number,
          ifsc_code: payout.ifsc_code,
          beneficiary_name: payout.beneficiary_name,
          transfer_mode: payout.transfer_mode  // NEFT, RTGS, or IMPS
        });

        // 4. Bank returns UTR (Unique Transaction Reference)
        if (bankResponse.status === 'success') {
          // 5. Insert into sp_v2_settlement_bank_transfers
          await db.query(`
            INSERT INTO sp_v2_settlement_bank_transfers (
              settlement_batch_id, merchant_id, amount_paise,
              bank_account_number, ifsc_code, transfer_mode,
              utr_number, status, transfer_date, created_at
            ) VALUES ($1, $2, $3, $4, $5, $6, $7, $8, NOW(), NOW())
          `, [
            payout.batch_id,
            payout.merchant_id,
            payout.amount_paise,
            payout.account_number,
            payout.ifsc_code,
            payout.transfer_mode,
            bankResponse.utr,        // ✅ Real UTR from bank
            'COMPLETED',
            new Date()
          ]);

          // 6. Mark queue item as completed
          await db.query(`
            UPDATE sp_v2_bank_transfer_queue 
            SET status = 'completed', processed_at = NOW() 
            WHERE id = $1
          `, [payout.id]);

          console.log(`✅ Payout completed: ${bankResponse.utr}`);
        } else {
          throw new Error(`Bank rejected: ${bankResponse.error}`);
        }

      } catch (error) {
        // 7. Mark as failed
        await db.query(`
          UPDATE sp_v2_bank_transfer_queue 
          SET status = 'failed', error_message = $2, updated_at = NOW() 
          WHERE id = $1
        `, [payout.id, error.message]);
      }
    }
  }

  async callBankAPI(payoutDetails) {
    // Integration with ICICI, HDFC, Axis Bank APIs
    // This is what needs to be implemented

      method: 'POST',
      headers: {
        'Authorization': 'Bearer YOUR_BANK_API_KEY',
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        account_number: payoutDetails.account_number,
        ifsc_code: payoutDetails.ifsc_code,
        amount: payoutDetails.amount,
        beneficiary_name: payoutDetails.beneficiary_name,
        transfer_mode: payoutDetails.transfer_mode,
        remarks: 'Settlement payment'
      })
    });

    return {
      status: 'success',
      utr: 'ICICI20250107123456789',  // Real UTR from bank
      bank_ref: 'REF123456'
    };
  }
}
```
